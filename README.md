# Welcome to my GitHub!

Here are the tools I've written. Some come from my research at the Stowers Institute, where I work as a researcher. The rest are projects from my free time, mostly focused on music expressivity and editors for MPE and other advanced controllers.

I will keep adding new software and the analysis code from my publications, so keep an eye on this page.

Mixing two activities on one account can make it hard to read, so the projects are grouped by theme.

| Project | What it does | Language |
|---|---|---|
| [barcodeNinja](https://github.com/SimonBourdareau/barcodeNinja) | Flexible demultiplexing of combinatorial barcodes in FASTQ files | C++ |
